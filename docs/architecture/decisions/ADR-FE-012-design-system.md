# ADR-FE-012: Propuesta de sistema visual

> **Estado: propuesta abierta; no aprobada.** No selecciona librería, estrategia
> de estilos, tokens ni reemplazo del diseño existente.

PR #47 recomendó evaluar tokens semánticos y primitivas accesibles antes de
componentes específicos. Puede revisarse como criterio de calidad visual junto
con la aplicación React/Vite actual, sin adoptar dependencia ni importar código
del prototipo por esta nota.

Toda elección futura requiere necesidad concreta, revisión de accesibilidad,
compatibilidad con la interfaz existente y aprobación correspondiente. El
prototipo es referencia visual únicamente, no fuente de comportamiento o
contratos.
