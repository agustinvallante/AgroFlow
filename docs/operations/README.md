# Operación

Este directorio contendrá las guías necesarias para desplegar y sostener AgroFlow:

- ambientes y configuración segura;
- observabilidad y alertas;
- copias de seguridad y restauración;
- respuesta a incidentes;
- objetivos de disponibilidad y recuperación;
- runbooks de n8n, base de datos y API.

Estas definiciones dependen de OD-008, OD-010 y OD-011. No deben presentarse como resueltas hasta aprobar las decisiones correspondientes.
