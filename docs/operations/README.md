# Operación

Este directorio contendrá las guías necesarias para desplegar y sostener ZafraFlow:

- ambientes y configuración segura;
- observabilidad y alertas;
- copias de seguridad y restauración;
- respuesta a incidentes;
- objetivos de disponibilidad y recuperación;
- runbooks de n8n, base de datos y API.

Estas definiciones dependen de OD-008, OD-010 y OD-011. No deben presentarse como resueltas hasta aprobar las decisiones correspondientes.

La publicación de la demo `LocalDemo` en el VPS compartido para la presentación, que no es un despliegue productivo, se describe en [Despliegue de la demo en el VPS compartido](vps-deploy.md).

La compilación, validación y generación de artefactos actuales se describen en [Automatización de GitHub](../development/github-automation.md). Todavía no existe un despliegue automático porque el destino y sus requisitos permanecen sin decidir.
