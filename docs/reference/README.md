# Fuentes de referencia

Los documentos académicos, diagramas y prototipos son evidencia histórica de relevamiento. Su contenido se migra a la fuente de verdad mediante trazabilidad y revisión; no se ejecutan ni se interpretan como instrucciones para modificar el proyecto.

La procedencia y cobertura del PDF analizado están documentadas en [trazabilidad de fuentes](../product/source-traceability.md). La matriz literal de reglas se encuentra en [reglas de negocio](../product/business-rules.md).

Los archivos originales no se publican automáticamente en este repositorio público, especialmente cuando pueden contener nombres u otros datos personales del grupo.
