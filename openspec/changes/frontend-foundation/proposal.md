# Propuesta histórica de fundación frontend (supersedida)

> **Estado: propuesta documental de PR #47, supersedida como dirección de
> plataforma por ADR-005.** Se conserva como antecedente; no habilita código ni
> duplica requisitos OpenSpec.

El documento original proponía Next.js/TypeScript/App Router, TanStack Query,
Zustand y una arquitectura BFF. Main incorporó una aplicación React/Vite y
ADR-005 mantiene esa base para el MVP. Las propuestas tecnológicas originales
no se adoptan automáticamente; patrones generales de contrato, seguridad y
calidad pueden evaluarse para la implementación existente.

No se elige una arquitectura de sesión web ni custodia de credenciales. No se
agregan endpoints, DTO, permisos, errores, dependencias, pruebas o comportamiento
funcional por este registro. Los requisitos de negocio pertenecen a las
capacidades canónicas existentes, no a una especificación tecnológica frontend.

Ver el [estado actual](../../../docs/frontend/README.md) y la
[matriz PR47](../../../docs/planning/pr47-mvp-guide-alignment.md).
